# Publication et sécurité

Ce dépôt est une archive technique publique de projets d'ingénierie logicielle et systèmes.

Avant toute nouvelle publication, vérifier que le changement ne contient pas :

- clé privée, jeton, mot de passe ou fichier `.env` ;
- document d’identité, relevé, certificat ou donnée de contact non nécessaire ;
- dépendance vendoriée ou artefact de compilation ;
- énoncé, corrigé ou ressource dont la redistribution est interdite.

Un problème de sécurité peut être signalé directement à Luis Fernandes via son
profil GitHub : <https://github.com/Luis1454>.
