# Modern C++ Object-Oriented Systems & Templates

Modern C++ progression covering RAII resource management, object-oriented encapsulation, polymorphism, operator overloading, and template metaprogramming.

## Technical Overview

- **Primary Stack:** C++20, STL, Templates, OOP
- **Core Language:** C++

## Key Architecture & Features

- RAII (Resource Acquisition Is Initialization) and smart pointers
- Polymorphism, abstract base interfaces, and virtual tables
- Standard Template Library (STL) algorithms and containers
- Template classes and generic programming

## Build & Execution

```sh
make
```
