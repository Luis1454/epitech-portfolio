🚀 Project Setup Guide

🛠️ How to Start the Project

1. Configure the Cross-Platform Dependencies

Follow the instructions based on your operating system:

On Ubuntu:
./ubuntu_installer.sh
On Fedora:
./fedora_installer.sh
On Windows:
./windows_install.bat

2. Execute the Project with CMake

Generate Configuration Files:
cmake .
Compile the Project:
cmake --build .
Launch the Server:
./r-type_server
Launch the Client:
./r-type_client
