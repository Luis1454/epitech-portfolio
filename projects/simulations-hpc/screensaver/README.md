# MyScreensaver — Real-Time Procedural Graphics Animation

Modular real-time screensaver rendering procedural visual animations, trigonometric waves, and particle physics in CSFML.

## Technical Overview

- **Primary Stack:** C, CSFML
- **Core Language:** C

## Key Architecture & Features

- Procedural mathematical animations and trigonometric vector fields
- Dynamic color cycling and alpha blending
- Modular scene selection with keyboard and CLI switching
- Frame synchronization targeting smooth 60 FPS display

## Build & Execution

```sh
make
./my_screensaver [id]
```
