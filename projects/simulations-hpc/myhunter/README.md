# myHunter — 2D Arcade Game Engine & Sprite Animation

2D Arcade shooter featuring hardware-accelerated sprite animation, event-driven user interaction, frame rate regulation, and high-score tracking.

## Technical Overview

- **Primary Stack:** C, CSFML
- **Core Language:** C

## Key Architecture & Features

- Sprite sheet animation with delta-time frame pacing
- Cursor collision detection with moving targets
- Score and life management with dynamic HUD rendering
- Audio effect triggering and music streaming

## Build & Execution

```sh
make
./my_hunter
```
