# myPaint — 2D Raster Graphics & Canvas Editor

GUI drawing application featuring modular tool palettes, layer manipulation, custom brush dynamics, and color selection.

## Technical Overview

- **Primary Stack:** C, CSFML graphics engine
- **Core Language:** C

## Key Architecture & Features

- Vector & raster tools: brush, pencil, eraser, shapes, paint bucket
- Interactive palette, RGB/HSV color picker, line thickness adjustments
- File export/import for standard image formats (BMP, PNG)
- Responsive UI layout with toolbars and menu cascades

## Build & Execution

```sh
make
./my_paint
```
