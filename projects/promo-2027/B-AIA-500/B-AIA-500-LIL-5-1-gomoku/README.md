# B Aia 500 Lil 5 1 Gomoku

> Projet Epitech · B-AIA-500 · promo-2027

Le Gomoku est un jeu de stratégie qui se joue sur une grille, souvent de 20X20 cases, avec deux joueurs qui placent chacun leur tour un pion de leur couleur (noir ou blanc) sur une case vide. L'objectif est d'aligner cinq pions consécutifs horizontalement, verticalement ou en diagonale avant l'adversaire. À la différence du jeu de morpion, il faut cinq pions…
