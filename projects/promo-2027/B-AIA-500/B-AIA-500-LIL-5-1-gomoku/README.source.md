# 🚀 Guide de configuration du projet


## 🎯 But du projet:

Le Gomoku est un jeu de stratégie qui se joue sur une grille, souvent de 20X20 cases, avec deux joueurs qui placent chacun leur tour un pion de leur couleur (noir ou blanc) sur une case vide. L'objectif est d'aligner cinq pions consécutifs horizontalement, verticalement ou en diagonale avant l'adversaire. À la différence du jeu de morpion, il faut cinq pions consécutifs au lieu de trois, ce qui rend le jeu plus complexe et stratégique. Le premier joueur à former cet alignement de cinq pions remporte la partie. Le Gomoku est populaire pour son équilibre entre simplicité des règles et profondeur stratégique, attirant aussi bien les amateurs que les compétiteurs.

## 🛠️ How to Start the Project

Follow these steps to set up and run the project locally:

1. **Compile le projet**
   ```bash
     make re
     ```
   - Vérifier si ça a bien généré l'exécutable et les deux fichiers exe des deux joueurs


2. **Pour effacer les executable ou binaire:**
   ```bash
     make fclean
     ```
