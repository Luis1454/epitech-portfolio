# Standard Template Library (STL) Containers & Iterators

> Object-Oriented & Generic C++ Paradigms

Effective usage of std::vector, std::list, std::map, and bidirectional iterator traversal patterns.

## Architecture & Conception

Selection of optimal container topologies based on asymptotic time complexities for search, insertion, and deletion.

## Primitives & Spécifications Implémentées

- `Sequence containers (vector, list)`
- `Associative key-value containers (map)`
- `Iterator navigation and range-based operations`

## Compilation & Exécution

```bash
make
```

- **Déterminisme** : Exécution pure sans effets de bord non contrôlés.
- **Gestion Mémoire** : Zero fuite mémoire (validé sous Valgrind / AddressSanitizer).
