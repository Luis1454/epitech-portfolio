# Pushswap — Constrained Double-Stack Sorting Optimization

Highly constrained algorithmic sorting challenge sorting a list of integers across two stacks (l_a and l_b) using a restricted instruction set (sa, sb, pa, pb, ra, rb, rra, rrb).

## Technical Overview

- **Primary Stack:** C, Stack Data Structures, Algorithmic Optimization
- **Core Language:** C

## Key Architecture & Features

- Radix sort and chunk-based sorting algorithms minimizing operation count
- Operation optimization reducing redundant reciprocal commands
- Scales efficiently from small arrays to 10,000+ integers

## Build & Execution

```sh
make
./push_swap 4 67 3 87 23
```
