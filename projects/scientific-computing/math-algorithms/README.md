# Numerical Mathematics & Scientific Algorithms

Collection of applied numerical computing and scientific calculation utilities in Python and C.

## Included Modules

- **101pong:** 3D ball velocity vector calculation and spatial paddle collision detection.
- **102architect:** 2D affine transformations (translation, scaling, rotation, reflection) using matrix multiplication.
- **103cipher:** Symmetric encryption and decryption using matrix inversion and Hill cipher mechanics.
- **104intersection:** 3D geometric ray-surface intersection solving quadratic equations for spheres, cylinders, and cones.
- **105torus:** Numerical root finding comparing Bisection, Newton-Raphson, and Secant methods for quartic polynomial equations.
- **106bombyx:** Population dynamics simulation based on the logistic map and chaotic bifurcation modeling.
- **107transfer:** Laplace transform and transfer function frequency response evaluation.
- **108trigo:** Matrix trigonometric functions (exp, cos, sin, cosh, sinh) computed via Taylor series expansions.
- **110borwein:** Numerical definite integrals comparing Midpoint, Trapezoidal, and Simpson rules on Borwein integrals.

## Execution

```sh
python3 102architect/102architect [args]
python3 103cipher/103cipher [args]
```
