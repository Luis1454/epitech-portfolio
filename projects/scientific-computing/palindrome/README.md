# Palindrome — Numerical Base Transformation & Palindrome Solver

Number theory utility computing forward and reverse palindrome iteration counts across various numerical bases (from base 2 to base 36).

## Technical Overview

- **Primary Stack:** C, Number Theory, Discrete Mathematics
- **Core Language:** C

## Key Architecture & Features

- Arbitrary base conversion (base 2 to 36)
- Forward iteration and reverse solution search
- Min/max iteration constraints and candidate filtering

## Build & Execution

```sh
make
./palindrome -n 47 -b 10
```
