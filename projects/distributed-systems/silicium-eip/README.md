# Silicium Network — Decentralized IoT Compute & ELF Partitioner

High-throughput distributed computing protocol harnessing low-power IoT devices via Solana and Anchor. Features a containerized C++ ELF binary partitioner and recursive task delegation protocols.

## Technical Overview

- **Primary Stack:** Rust, C++, Solana / Anchor, Docker, Distributed Systems
- **Core Language:** Rust, C++, Go, Python

## Key Architecture & Features

- Micro-runtime with <128 KB memory footprint designed for constrained embedded devices
- C++ ELF binary partitioner slicing computational jobs for edge node execution
- Solana smart contracts in Rust/Anchor for decentralized task verification and settlement
- Dockerized cluster deployment and consensus verification

## Build & Execution

```sh
make
```
